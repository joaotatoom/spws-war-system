# SPWS — Strategic War Planning System

Protótipo inicial do painel de comando para organização de operações no Tribal Wars.

## Versão

Alpha 0.0.1

## Como publicar no GitHub Pages

1. Envie todos os arquivos deste pacote para a raiz do repositório `spws-war-system`.
2. No GitHub, abra **Settings → Pages**.
3. Em **Build and deployment**, selecione **Deploy from a branch**.
4. Escolha a branch **main** e a pasta **/(root)**.
5. Clique em **Save**.

## Estrutura

- `index.html`: Dashboard principal.
- `assets/css/style.css`: identidade visual e responsividade.
- `assets/js/app.js`: navegação clicável.
- `pages/`: páginas futuras.
- `data/`: arquivos JSON futuros.
- `docs/`: documentação do projeto.

## Status atual

Dashboard visual funcional, com todos os botões clicáveis e páginas provisórias.
